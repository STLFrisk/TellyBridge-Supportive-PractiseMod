# TellyBridge Trainer 1.8.9 — v1.0.0

首个发布版本。纯客户端的 telly bridge 练习仪表盘：把放块节奏、起跳时机、俯仰角和落点可视化出来，
方便对着数字改动作。**不改变任何游戏行为**——不自动放置、不自动瞄准、不改触及距离，也不动服务器数据包。

## 安装

1. 装好 Minecraft **1.8.9** + Forge **11.15.1.2318**
2. 把 `TellyBridgeTrainer-1.8.9-1.0.0.jar` 放进 `.minecraft/mods/`
3. 启动客户端，HUD 出现在左上角

无需任何前置模组，单机 / 多人通用，不需要 OP。

## 功能

### 练习仪表盘

| 指标 | 含义 |
| --- | --- |
| `Cadence` / `Jitter` | 相邻两块的时间间隔均值 / 标准差，手速节奏与稳定性 |
| `J>P` | 起跳 → 空中第一块的延迟，telly 手感的核心指标 |
| `B/Jump` | 平均每跳放几块 |
| `Miss` | 起跳后落地却一块没放出来的次数 |
| `Air` | 本次跳跃还剩多少秒落地（以上一次真实滞空时长为基准） |
| `Blk` | 本次跳跃已放几块 |
| `Spd` | 水平速度，用来发现"回头时掉速" |
| `Pitch` | 当前俯仰角，落在自定义靶带内变绿 |

### 落点提示

* 绿色半透明幽灵方块标出**桥末端外侧、现在真的能放上去的那一格**，随着补块自动前移
* 白色小十字 = 该格的瞄准点（相邻支撑面中心）；屏幕上的绿色幽灵准星 = 同一个点的投影
* 面板给角度：`R15 D7` 表示还要右转 15°、下压 7°；已经是这一格时显示 `OK`
* **只在空中提示**，站在方块上自动隐藏

### 幽灵路线

* 按 `J` 把当前这趟存成幽灵，破纪录时自动更新
* 可开穿透显示，方便对比自己和最佳记录的走位

### 命令

`/telly`（别名 `/tbt`），纯客户端命令，不发给服务器，没 OP 也能用。完整列表与示例见 README。

## 已知限制

* 方块计数以客户端世界里**真的出现方块**为准，约 1 tick 确认延迟；高延迟服务器更慢
* 视线外 / 被服务器拒绝的放置不计入（这是期望行为）
* `J>P` 依赖客户端 `onGround`，极端卡顿下可能少计一次起跳
* 落点提示扫描范围 4 格、触及上限 5 格；缺口更远时不会提示（那时也确实放不到）
